{% else %}

  1. The MCP endpoint

    {{ mcp_url }}
    {% if not public_url %}

    Start the server with --public-url to show its real address here.

    {% endif %}

    Send the key as x-api-key: <key> or Authorization: Bearer <key>. The REST API under /api takes the same headers.

  2. Mint a key

    On the server, write a new key into a file only its owner can read (mode 0600). The command refuses to overwrite a file and prints only the file's path, never the key. You can also make one under Keys.

    python -m cairn.server key-create --db PATH --label L --out FILE

    To retire every key with a label: python -m cairn.server key-revoke --db PATH --label L

  3. Keep the key in an env file

    On each machine an agent runs on, keep the address and the key in a file only you can read (mode 0600), for example cairn.env:

    CAIRN_URL={{ app_url }}
CAIRN_API_KEY=<the key from key-create>

  4. Give it to the agent

    Load the file into the agent's environment and name the variable in the agent's MCP config, so the config itself holds no key. The connect guide has the steps for each client.

  5. Choose the project

    Use one project per kind of work — a code repository (named after the repo), team decisions and runbooks, memory for an AI feature, meetings, business documents, or personal notes — from guided setup, Projects, or the new_project tool.
